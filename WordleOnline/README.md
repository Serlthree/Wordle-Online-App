2 week project using Firestore Transactions and Views (no Compose).
What it is:
1. A 2 player Wordle Online game with matchmaking, statistics, and chat
2. Using MVVM architecture, Fragments, and xml (instead of Compose), Kotlin Flows to track updates
3. Firebase transactions and Firestore (database) for storing stats and match info, along with match info updates
4. Vico to graph statistics
4. Basic sign in with email and password (to track stats)
5. Flip animations, custom keyboard, clean UI design

Due to the time crunch when implementing, some refactoring should probably be done, most importantly:
1. Getting rid of hardcoded color values in some UI Fragments
2. Cleaning up TODO comments and adding proper documentation
3. Adding a rigorous test suite to make testing scalable
4. Cleaning up some confusing logic on what to reset and why. (Done in documentations.)

Possible improvements and additions:
1. More modern sign in (using Google, Facebook, etc, also revamping the UI for sign in)
2. Leaderboard
3. Guest option instead of requiring a sign in.
